# 道の駅周遊コンシェルジュ 企画書

## 1. サービスコンセプト

「今からどこをどう巡れば一番楽しめるか」を自動で考えてくれる、**道の駅版トラベルコンシェルジュ**。

現在地・時刻・こだわり条件をもとに、選択した道の駅を効率的に周遊するルートを提案し、訪問記録による収集要素で継続利用を促す。

---

## 2. 背景・課題(As-Is)

- 閉店時間が迫るとき、今いる地点からどう巡れば多くの道の駅を回れるか考えるのが大変
- 着いてみるとレストラン等がすべて閉まっていてがっかりすることが多い
- 「最短経路」と「自分にとって良い経路」が一致しない(高速は使いたくない、山道は避けたい)
- 定休日・臨時休業日を見落とす
- トイレが汚く、行ってみて後悔することが多い
- 周辺観光も含めてルートを立てたいが、その効率的な経路を考えにくい
- 行ったことのある道の駅を記録したい

---

## 3. 目指す姿(To-Be)

- 現在地から、以下を考慮して選択した道の駅を効率的に周遊するルートを提案する
  - 営業時間・営業日
  - 人気度・トイレのきれいさ
  - 周辺観光
  - こだわりルート(高速回避)
- 訪問済みの道の駅を記録し、達成率・バッジ・キャラ等の収集要素で継続利用を促す

---

## 4. 主要機能案

- [ ] 営業時間・定休日・道路条件を考慮した道の駅の最適周遊ルート作成
- [ ] 道の駅の施設情報、人気度、トイレ、周辺観光情報の確認
- [ ] 訪問済み道の駅の記録・達成率表示・バッジやキャラ等の収集要素

---

## 5. 参考サービス・参考資料

| 参考 | 参照する要素 |
|------|-------------|
| Google Maps | 経路検索・地図UI |
| 全国「道の駅」連絡会 | 施設・営業時間などの基本情報 |
| 道の駅ナビ 等 | 訪問記録・チェックイン・達成率機能 |
| アプリ「道の駅めぐり」 | 訪問記録・収集要素 |
| アプリ「mapfanassist」 | 有料道路の回避 |
