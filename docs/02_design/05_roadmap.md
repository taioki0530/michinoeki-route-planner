# 実装の進め方(スプリント分割の目安)

外部設計で決めた土台([00_overview.md](./00_overview.md)〜[03_external-interfaces.md](./03_external-interfaces.md))を前提に、機能を縦切り(画面〜データまで一気通貫)で小さく積み上げる進め方の目安。各ステップは目安であり、進めながら見直してよい。

| ステップ | 内容 | 完了時にできること |
|---------|------|---------------------|
| 1 | ログイン + 道の駅一覧・詳細の表示のみ(手動データ数件でOK) | ログインして道の駅情報を見られる |
| 2 | 現在地入力 + 単純な経路提案(時間枠なし、距離最小化のみ = L1+L2相当) | 最短距離ベースでルートが出る |
| 3 | 営業時間・定休日を制約に追加(OPTW化 = L3の本体) | 「閉まっている道の駅」が候補から除外される |
| 4 | 高速道路回避オプション | 道路条件の希望を反映できる |
| 5 | チェックイン(訪問記録) | 訪問済みを記録できる |
| 6 | 実績画面(都道府県別・全国達成率) | 達成率が見られる |

## 各ステップと外部設計書の対応

- ステップ1: [02_data-model.md](./02_data-model.md) の Michinoeki/User、[01_screens.md](./01_screens.md) のS1/S5
- ステップ2〜4: [00_overview.md](./00_overview.md) のL1〜L3境界、[01_screens.md](./01_screens.md) のS2〜S4
- ステップ5〜6: [02_data-model.md](./02_data-model.md) のVisit、[01_screens.md](./01_screens.md) のS6/S7

## 進め方の考え方

- ステップの最後に必ず「実際に動くもの」が残るようにする(内部設計だけ進めて何も動かない状態を作らない)
- 各ステップに着手する直前に、対応する設計書ファイルの詳細(画面の細部仕様、バリデーション等)を詰めてから実装する
- 道の駅データの調達方法(要件定義書 未決事項1)が未確定でも、ステップ1は手動で数件分のダミーデータを用意すれば着手できる
