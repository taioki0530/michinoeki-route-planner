| 設計対象範囲 | MVPスコープのみ |

## 書き方の方針

外部設計書は「後から変えると手戻りが大きい土台」を中心に書き、機能ごとの詳細な振る舞い(バリデーション仕様・細かいUI状態など)はあえて書ききらない。詳細は各機能に着手する直前に、該当ファイルに追記・更新する形で育てていく。

- 土台として先に決める: 画面遷移の骨格、データモデル、外部インターフェースの境界
- 実装直前に詰める: 各画面の詳細仕様、バリデーション、エラーハンドリング
